Ce qui marche · ce qui est bloqué

Prouvé sur ce run

  • Sourcing gratuit via l'API entreprises de l'État — 303 cibles, 0 crédit.
  • Firmographie fiable (SIREN 100 %, dirigeant 100 %, effectif 91 %).
  • Règles d'exclusion qui apprennent : 45 → 75 % en trois patchs.
  • Messages rédigés sourcés, sans invention (8,4/10), jamais envoyés.
  • Discipline base + statuts tenue ; run rejouable, réversible.

Hors périmètre (pas de clé)

  • Emails de contact vérifiés (FullEnrich) — contacts = dirigeants nommés, sans adresse.
  • Scraping de sites / registres de groupes (Bright Data) — d'où les filiales résiduelles.
  • Signaux presse : bon outil pour l'embauche/le growth, inadapté à MemoVAL dont le déclencheur est un état firmographique (dirigeant 60-68 + société mûre), capté à 100 % au sourcing.
