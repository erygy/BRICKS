# concept-to-signals

Exécute uniquement : STRATEGIST → vague d'ARCHITECTS → fusion → CRITIC →
BROKER → `score_v2.py check` + run d'identifiabilité sur un univers
échantillon (registre gratuit, ~200-300 candidats suffisent).

Livrables :
- `staging/theses.json` — les thèses falsifiables ;
- `staging/tree-v1.json` — l'arbre calibré (signaux kept, poids en classes,
  clusters, proxies mappés, inobservables → questions de qualification) ;
- le receipt d'identifiabilité (distribution des scores, bandes) ;
- la liste des SONDES Day-1 (capacités presumed à confirmer).

C'est le livrable de « compréhension du besoin » : on peut le mettre devant
un client/associé AVANT d'avoir dépensé un centime — l'arbre de signaux est
lisible par un humain (claims en français, rationales, questions).
